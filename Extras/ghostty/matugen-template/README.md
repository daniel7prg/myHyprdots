<h1 align="center">Matugen Template</h1>

<h2>STEPS</h2>

* Copy 'material-u' into $HOME/.config/matugen/templates/
* Add the followinf lines to the config.toml file
```
[templates.ghostty]
input_path = './templates/material-u'
output_path = '~/.config/ghostty/themes/material-u'
```
* Select any wallpaper to apply colors
* Enjoy!!
